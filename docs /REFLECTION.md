# Reflection
## Introduction
This assignment helped me understand PL/SQL GOTO statements, stored functions, exception handling, and how functions can be used in SQL
statements. I also gained practical experience working with Oracle SQL*Plus and organizing my work in a GitHub repository.
## Challenges I Encountered
One of the challenges I encountered was compilation errors when creating my functions. 
I had to check the Oracle error messages and correct the syntax.I also encountered an issue because my EMPLOYEES table contains a SALARY column rather than a MONTHLY_SALARY column. 
I corrected the functions and queries to use the actual SALARY column.Another challenge was remembering the correct PL/SQL syntax, especially END IF; and the correct structure of exception handling.
These errors helped me understand the importance of checking the table structure using commands such as DESC employees; and checking function errors using SHOW ERRORS.
## What I Learned
Through the GOTO tasks, I learned how labels and GOTO statements can control the flow of a PL/SQL program. I also learned that GOTO should be 
used carefully because unnecessary jumps can make a program difficult to understand.
I learned how to create stored functions in PL/SQL and how functions can receive parameters, perform calculations, and return values. 
For example, I created functions for calculating annual salary and estimating tax.
## What I Improved
I learned that testing each function separately makes it easier to identify where an error occurs. I also learned the importance of keeping SQL files organized according to the required GitHub repository structure.
## Conclusion
Overall, this assignment improved my understanding of PL/SQL programming and stored functions.
I learned how to create functions, use conditional statementshandle exceptions, and call functions from SQL queries. 
Although I encountered several errors during the practical work, 
solving them helped me understand the concepts better and improved my confidence when working with Oracle PL/SQL.
